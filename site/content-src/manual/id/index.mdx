## Pasang dalam satu perintah

Atlas-skill `v{{VERSION}}` berjalan dengan **Node.js 18+** dan **nol dependensi npm runtime** untuk penginstal serta pemeriksaan statisnya. Pilih agen Anda atau pasang untuk seluruh folder agen sekaligus:

<Tabs>
  <TabItem label="Semua Agen">
    ```sh
    npx --yes github:Crelami-Dev/atlas-skill install --agent all --with-rules
    ```
  </TabItem>
  <TabItem label="Antigravity">
    ```sh
    npx --yes github:Crelami-Dev/atlas-skill install --agent antigravity --global --with-rules
    ```
  </TabItem>
  <TabItem label="Claude Code">
    ```sh
    npx --yes github:Crelami-Dev/atlas-skill install --agent claude
    ```
  </TabItem>
  <TabItem label="Codex + QA">
    ```sh
    npx --yes github:Crelami-Dev/atlas-skill install --agent codex --with-rules --with-qa
    ```
  </TabItem>
</Tabs>
