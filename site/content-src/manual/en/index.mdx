## Install in one command

Atlas-skill `v{{VERSION}}` requires **Node.js 18+** with **zero runtime npm dependencies** for its installer and static phase gates. Choose your agent or install into every project agent directory at once:

<Tabs>
  <TabItem label="All Agents">
    ```sh
    npx --yes github:Crelami-Dev/atlas-skill install --agent all --with-rules
    ```
  </TabItem>
  <TabItem label="Antigravity">
    ```sh
    npx --yes github:Crelami-Dev/atlas-skill install --agent antigravity --global --with-rules
    ```
  </TabItem>
  <TabItem label="Claude Code">
    ```sh
    npx --yes github:Crelami-Dev/atlas-skill install --agent claude
    ```
  </TabItem>
  <TabItem label="Codex + QA">
    ```sh
    npx --yes github:Crelami-Dev/atlas-skill install --agent codex --with-rules --with-qa
    ```
  </TabItem>
</Tabs>

<div class="atlas-callout atlas-callout--register">
  <span class="atlas-callout__label">First Prompt in Your Agent Session</span>
  <p>Once installed, open a fresh agent session in your project root and run a prompt such as:</p>
  <pre><code>/atlas-frontend Build a light-mode architecture studio landing page using measured CSS tokens, Anime.js v4 motion, and verified 375/768/1440 px screenshots.</code></pre>
</div>
