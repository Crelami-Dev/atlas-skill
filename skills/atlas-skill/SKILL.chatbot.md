# ATLAS Skill (Chatbot Edition)

> **Phase 5 Release:** Inlined design knowledge, motion principles, contextual anti-AI-slop heuristics, and self-critique rubrics for standalone chatbot environments.

## 1. Standalone Operational Rules
- **Zero Terminal / Filesystem / CLI Dependencies:** Self-contained design decision trees and curated color/font pairings.
- **Honest Content Enforcement:** No fabricated metrics (no random `99.99%`, `10,000+ teams` unless provided in user brief).
- **The Two-Line Headline Discipline:** Headlines must not exceed two lines; budget 24-32 characters for impactful reading.
- **The 40% Focal Point Law:** Hero sections must command at least 40% of viewport area with an authentic focal subject.

## 2. Inlined Motion Design Intelligence
- **Easing Curves:**
  - Fast feedback (<600ms): `cubic-bezier(0.22, 1, 0.36, 1)`
  - Dramatic reveals (>=800ms): `cubic-bezier(0.16, 1, 0.3, 1)`
  - Panel slides: `cubic-bezier(0.76, 0, 0.24, 1)`
- **Stillness as Intentional Craft:** For operational dashboards, data-dense UIs, or minimal products, motion should be zero on entrance; focus on instant responsiveness and tabular readability.
- **Reduced Motion Obligation:** Always provide `@media (prefers-reduced-motion: reduce)` fallbacks disabling spatial movement.

## 3. Contextual Anti-AI-Slop Mental Rubric
Before presenting HTML/CSS to the user, mentally review:
1. Did I use gradient text without a specific brand reason? (If so, revert to solid high-contrast ink).
2. Did I create three identical feature cards each topped with a tiny icon in a pastel circle? (If so, compose an asymmetric narrative split or editorial list).
3. Did I put a generic eyebrow label like "WHY CHOOSE US" or "KEY FEATURES"? (If so, delete it or fold it into the heading).
4. Did I default to AI assistant violet/indigo? (If so, choose a tailored palette like stone, charcoal, warm clay, or midnight ink).
5. Are there unmotivated emoji bullets? (If so, replace with authentic words or concise semantic badges).
6. *Contextual Exception Check:* If the user asked for a SaaS dashboard or metrics overview, structured cards and tabular data are legitimate and encouraged.
